# Сказано — диктовка для Mac

Говорите, и текст печатается в любое поле на Mac прямо по ходу речи.
Зажмите правый ⌥, и вместо русского в поле сразу пойдёт английский.
Распознавание и перевод работают на вашем Mac, без облака и аккаунта. Бесплатно.

Сайт: https://guff86-cloud.github.io/skazano/

## Как пользоваться

- **Левый ⌥** — держите и говорите по-русски. Текст появляется по ходу речи,
  после паузы модель Whisper поправляет пунктуацию.
- **Правый ⌥** — говорите по-русски, в поле печатается английский перевод.
- **Esc** — отменить запись.

## Установка

1. Откройте скачанный файл и перетащите «Сказано» в «Программы».
2. Приложение пока не подписано сертификатом Apple, поэтому при первом запуске
   откройте «Системные настройки → Конфиденциальность и безопасность» и нажмите
   внизу «Всё равно открыть». Если macOS пишет, что приложение повреждено,
   выполните в Терминале:
   ```
   xattr -dr com.apple.quarantine "/Applications/Сказано.app"
   ```
3. Разрешите доступ к микрофону и распознаванию речи, затем включите «Сказано»
   в разделах «Универсальный доступ» и «Мониторинг ввода».
4. При первом запуске приложение один раз скачает модель распознавания:
   около 0,5 ГБ на Apple Silicon и 1,6 ГБ на Intel.

## Приватность

Звук обрабатывается на вашем Mac и не отправляется на серверы. Исключение одно
и включается только вами: если системный распознаватель на вашем Mac не знает
русский без сети, для живой печати можно разрешить облако Apple.
